# QuickCart Philippines

A web-based shopping and order management system developed as a Database Management Systems (DBMS) final project.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Main Features
- User registration and login
- Secure password hashing
- User authentication and protected pages
- Dashboard
- Product management (CRUD)
- Order management
- Order status updates
- Inventory stock updates

## How to Run Locally

### Requirements
- Python installed
- Visual Studio Code (recommended)

### Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal and navigate into the `quickcart` folder.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Initialize the database:

   `python init_db.py`

6. Start the application:

   `python app.py`

7. Open your browser and visit:

   `http://127.0.0.1:5000`

## Project Purpose

QuickCart demonstrates database integration, authentication, product CRUD operations, order processing, and inventory management.
